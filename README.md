# Ivan Golovach

Founder building [MealMark](https://usemealmark.com), [Radish](https://radish.money), and [Grain](https://github.com/IvGolovach/grain-protocol).

Solo operator shipping full-stack product work across web, iOS, and backend with an AI-agent pipeline: agents draft; I review, test, and own every change. CI, deploy checks, conformance tests, and reproducible research keep it honest.

## Current work

[**MealMark**](https://usemealmark.com) — a food-and-symptom diary. Meal history exports as Grain records: open, lossless, and parseable outside MealMark. The record format is the product, not a CSV afterthought.

[**Radish**](https://radish.money) — an iPhone app that turns grocery receipts into item-level household spending. Scan a receipt, review the extracted items, and see what actually drove the month — without connecting a bank account. [Radish Core](https://github.com/IvGolovach/radish-core)

[**Grain Protocol**](https://github.com/IvGolovach/grain-protocol) — an open protocol and conformance suite for portable, verifiable records: spec, reference SDKs, and test fixtures.
